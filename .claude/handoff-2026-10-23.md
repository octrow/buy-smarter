## Tooling quirk

In an `EnterWorktree` session plain `git` is refused (rtk rewrite vs the isolation guard):
call `/usr/bin/git <args>` as one simple command per Bash call. Outside worktrees plain git
works. Multi-line file edits: a scratchpad script run with `python3 script.py <files>`.
