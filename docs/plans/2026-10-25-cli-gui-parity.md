# Сверка CLI ↔ GUI (2026-10-25)

Правило Даниила 2026-10-25: CLI на 100% повторяет GUI, GUI — CLI. Любой выбор, ввод, исход, строка отчёта и
предложение после него, которые есть у одного входа, должны быть у другого. MCP и HTTP API — вне сверки.

Сверка — агент только на чтение по main после `cf8d08c`. Строки `file:line` — на тот момент. Мной перепроверен п. 1
(город); остальное — со слов агента, сверить по коду при работе над пунктом. Различия #26 (обучение) уже закрыты
шагом 10 плана `2026-10-24-wait-for-learning.md` и коммитом `ca6466e` (повтор поиска без повторных вопросов).

Колонка «Нет у» — чей вход отстаёт. «Решение» — предложение, решает Даниил.
