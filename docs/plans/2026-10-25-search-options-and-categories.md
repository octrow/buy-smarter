# План: параметры поиска и категории в обоих входах (сверка CLI ↔ GUI, пп. 2–4, 8–9, 11, 13)

Правило Даниила 2026-10-25: CLI на 100% повторяет GUI и наоборот. Сверка `docs/plans/2026-10-25-cli-gui-parity.md`:
пп. 1, 14, 18–22 закрыты; здесь — то, что есть только в одном входе:

- **GUI отстаёт:** п. 2 «только проверенные бренды», п. 3 «без сводки отзывов», п. 4 «не уточнять», п. 11
  изучение категории по запросу (с поиском в интернете и без, из заметок, итог, переобучение категории с данными).
- **CLI отстаёт:** п. 8 сохранённые маркетплейсы и исключённые бренды не читаются, п. 9 нет команды настроек, п. 13
  нет переключателей «Как оцениваем эту категорию».

Цель: всё, что пользователь может задать или сделать в одном входе, он может задать или сделать в другом, с тем же
итогом и теми же словами. MCP и HTTP API не меняются.

## Открытые вопросы

Решено 2026-10-25: Даниил принял все рекомендации В1–В10.

| # | Вопрос | Рекомендация | Почему |
|---|---|---|---|
| В1 | Где применять сохранённые маркетплейсы и исключённые бренды | Во входах (GUI, CLI) общей функцией, не в ядре. Выбранная — итог как у `learn-category` (тиры брендов, вещества), «Изучить» / «Переучить» с флажком «С поиском в интернете» (`--web/--no-web`), «Из заметок…» (выбор .md, как `learn FILE`), переключатели «Как оцениваем эту категорию» (тот же виджет, без «Повторить поиск»). Удаления нет (в CLI его тоже нет) | Всё, что CLI умеет с категорией, и ничего сверх |

| В9 | Место экрана в меню | Группа «Сервис», первым: «Категории», «Настройки поиска», «Состояние и ключи» | Это знания приложения, не покупка |

## Живой прогон (2026-10-25)

Рабочая база (копия до прогона), настоящий LLM, приложение — скрипт в окне offscreen, CLI — в той же базе.

- **Настройки → поиск.** `prefs set marketplaces kaspi`, `prefs set excluded_brands "Noname, AAT"` → `recommend
  "чехол для iphone 15"`: только Kaspi, в запросе «Без брендов: Noname, AAT», «Отсеяно: исключённый бренд ×1» (AAT).
  Noname в выдаче Kaspi не встретился, поэтому проверено на AAT. Приложение после запуска: «Настройки поиска» —
  `{'marketplaces': ['kaspi'], 'excluded_brands': ['Noname', 'AAT']}`, в форме отмечен только Kaspi.
- **Флажки формы.** «Только известные бренды» + выключенная «Сводка отзывов» против `--trusted-only
  --no-review-summary`: на чехле оба входа — одно и то же «Новых предложений нет: неизвестный бренд ×11, исключённый
  бренд ×1…»; на «смартфон до 150000» markdown-отчёты приложения и CLI совпали байт в байт, сводки нет в обоих.
- **«Искать без уточнений».** «крем» вопроса не задал. «подарок для мамы до 15000» спросил «Что именно ищем?»;
  кнопка → отчёт «Искал: духи — уточните запрос…», как `--no-clarify`; повторного вопроса нет. Лучший выбор разный:
  приложение перед поиском изучило «духи» (по умолчанию), CLI без терминала без `--learn` ищет без книг — так и задумано.
- **«Категории».** «Изучить» «термос» без интернета (19,7 с, ответ LLM из кэша) → статус «изучена», кнопка
  «Переучить», тиры и счётчики; «Переучить» → снова «изучена»; во время обучения видна «Отмена». «Состав» на экране
  → `category show` видит «включено вами»; `category set термос composition off` → экран видит «выключено вами».
- **Найдено и исправлено.** У «термоса» после включения «Состава» вручную экран писал «включено вами, но нет данных»,
  а ядро и `category show` — «включено вами» и «Оценка по составу»: обучение категории по характеристикам хранит
  пустую книгу веществ, и `composition_book` отдавал её как книгу. Теперь пустая книга — как её нет (тест в
  `tests/knowledge/test_profile.py`); `category show` после правки: «включено вами, но нет данных», «Оценка по
  характеристикам».
- **Замечено, вне плана.** «На OLX тоже ничего» в «Новых предложений нет» говорится и когда OLX не искали
  (маркетплейсы — только Kaspi). Пока висит вопрос, у отмеченного Kaspi стоит «пропущен» (этап прошлого шага).
  Полный прогон один раз упал аварийно внутри Qt; два следующих — зелёные (1691), не воспроизводится.
- **Уборка.** Таблица `category_knowledge` возвращена из копии до прогона (автообучение записало «духи», «крем»,
  обновило «чехол»; «термос» — тестовый), `prefs clear marketplaces/excluded_brands`.
