# План: переключатель на отчёте не привязывает категорию к найденному профилю (В4)

Из плана #25 (`2026-10-26-closer-composition-profile.md`, «Вне плана»). Переключатель «Как оцениваем эту
категорию» на отчёте «крема от акне» пишет запись «крем» с `parent` = найденный профиль «средства-от-акне»
(`gui/capability_toggles` → `knowledge/store.set_user_choice(..., parent=found)`, решение 13 Ф3). У записи
с родителем поиск останавливается на своём ключе, и любой крем («крем для рук») читает книги средств от акне.
CLI `category set` пишет ту же запись без `parent` — входы ведут себя по-разному.

## Решения

| # | Вопрос | Рекомендация | Почему |
|---|---|---|---|
| В1 | Что пишет переключатель | **Только выбор пользователя в свою запись, без `parent`**, как `category set`. Запись без книг и родителя — не профиль: поиск идёт дальше (похожий профиль по запросу), её выбор ложится сверху (решение 1 Ф3) | «крем от акне» по-прежнему читает «средства-от-акне», «крем для рук» — свой похожий профиль или ничего; CLI = GUI |
| В2 | Параметр `parent` у `set_user_choice` и `found` у `CapabilityToggles` | Удалить: других вызовов нет | Мёртвый путь, который снова приведёт к В4 |
| В3 | Записи с таким `parent`, уже созданные 0.8–0.9 | Не переносить. В рабочей базе таких нет (проверено 2026-10-27); отличить их от записи, которой родителя поставил пользователь или лечение, надёжно нельзя | Нет данных, на которых это нужно |
| В4 | Цена | Повторный поиск «крема от акне» снова спрашивает Jev о похожем профиле (как до переключателя) | Один вызов Jev за поиск, и он уже был в этом пути |

## Живой прогон (2026-10-27)

Рабочая база (копия до прогона), настоящий LLM, только Kaspi, без сводки отзывов.

- **Приложение, «крем от акне».** Найден «средства-от-акне», тип — «крем». Снятая галочка «Состав» («включено
  обучением» → «выключено вами») записала «крем» только с `capabilities.composition.user: false`, без `parent`.
- **CLI, «крем для рук».** Тип «крем»: запись без книг и родителя — поиск пошёл дальше, Jev похожего профиля не нашёл
  («no brand knowledge for 'крем'»), книги средств от акне не прочитаны; «Как оценивали: состав — выключено вами».
- **Уборка.** Таблица `category_knowledge` возвращена из копии (12 записей, без «крема»).
