# Установка приложения

[English version](install-desktop.md)

Окно buy-smarter можно поставить двумя способами: скриптом установки или готовой сборкой со
[страницы релизов](https://github.com/octrow/buy-smarter/releases/latest). Оба бесплатные, и ни одному
не нужен Python на компьютере.

| Система | Рекомендуем | Тоже можно |
|---|---|---|
| macOS | скрипт установки | `buysmarter-<версия>-macos-arm64.dmg` (без подписи, см. ниже) |
| Windows | `buysmarter-<версия>-windows-x64-setup.exe` | `…-windows-x64.zip`, скрипт установки |
| Ubuntu / Debian | `buysmarter_<версия>_amd64.deb` | скрипт установки |
| Другой Linux | скрипт установки | `buysmarter-<версия>-linux-x64.tar.gz` |

В таблице имена для обычных машин. Mac на Intel берёт `…-macos-x64.dmg`. Linux на ARM (Ubuntu 24.04
и новее) — `buysmarter_<версия>_arm64.deb` или `…-linux-arm64.tar.gz`. Windows на ARM ставит x64-установщик.

## Скрипт установки

macOS / Linux, в Терминале:

```bash
curl -LsSf https://raw.githubusercontent.com/octrow/buy-smarter/main/install.sh | sh
```

Windows, в PowerShell:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://raw.githubusercontent.com/octrow/buy-smarter/main/install.ps1 | iex"
```

Когда он закончит, приложение открывается командой:

```bash
buysmarter gui
```

На Mac это рекомендуемый путь: через браузер ничего не скачивается, поэтому macOS не спрашивает про
неизвестного разработчика. Повторный запуск скрипта обновляет приложение.

## Ubuntu и Debian: пакет .deb

Скачайте `buysmarter_<версия>_amd64.deb` и откройте его (установит Центр приложений) или в Терминале:

```bash
sudo apt install ./buysmarter_<версия>_amd64.deb
```

После этого buy-smarter появится в меню приложений. Нужные окну системные библиотеки apt поставит сам.
Нужна Ubuntu 22.04 или новее, Debian 12 или новее. Удалить: `sudo apt remove buysmarter` (история, настройки и ключи
останутся). Обновить: поставить более новый `.deb` так же.

## Windows: программа установки

Скачайте `buysmarter-<версия>-windows-x64-setup.exe` и запустите. Она ставит приложение только для вашего
пользователя, поэтому не просит прав администратора, и добавляет buy-smarter в меню «Пуск». Если
SmartScreen предупредит, см. ниже. Удалить: **Параметры → Приложения**. История, настройки и ключи
останутся. Обновить: запустить более новую программу установки.

## macOS: образ диска

Откройте `buysmarter-<версия>-macos-arm64.dmg` и перетащите buy-smarter на папку «Программы» рядом.
При первом запуске нужны шаги Gatekeeper ниже, потому что приложение не подписано. Удалить: перенести его
из «Программ» в Корзину. Скрипт установки на Mac по-прежнему самый простой путь: без запроса Gatekeeper.

## Готовая сборка

Скачайте архив для своей системы, распакуйте куда угодно (подойдёт домашняя папка) и запустите:

- **Windows:** `buysmarter\buysmarter.exe`.
- **Linux:** `buysmarter/buysmarter`. Собрано на Ubuntu 22.04; на более старых дистрибутивах может не
  хватить glibc.
  Если запуск обрывается с «Could not load the Qt platform plugin "xcb"», установите `libxcb-cursor0`
  (`sudo apt install libxcb-cursor0` в Ubuntu и Debian).
- **macOS:** `buysmarter.app`.

Сборки не подписаны: подпись стоит ежегодных денег, которые проект не платит. При первом запуске система
предупредит.

**Windows SmartScreen.** Если появилось «Система Windows защитила ваш компьютер», нажмите
**Подробнее**, затем **Выполнить в любом случае**.

**macOS Gatekeeper.** Если macOS пишет, что приложение «не удаётся открыть, так как не удалось проверить
разработчика»:

1. Нажмите **Готово** (не «Переместить в корзину»).
2. Откройте **Системные настройки → Конфиденциальность и безопасность**.
3. Пролистайте до сообщения о `buysmarter.app` и нажмите **Всё равно открыть**.
4. Подтвердите паролем. Дальше приложение открывается как обычно.

## Что ещё нужно

- **Google Chrome** для Ozon.kz. Приложение использует уже установленный Chrome и своего браузера не
  везёт. Без Chrome Kaspi и OLX работают, а в отчёте написано, что Ozon пропущен. В первый раз нажмите
  **Пройти проверку Ozon** на экране **Состояние и ключи**: приложение один раз откроет Chrome, чтобы пройти антибот-страницу Ozon.
- **Казахстанский интернет** для Kaspi.kz. Из-за границы или из дата-центра Kaspi отказывает.
- **По желанию: AI-ключ.** Вставьте его в блок **AI-ключ** на экране **Состояние и ключи**, и появятся разбор запроса и сводка
  отзывов. Ключ хранится в системном хранилище паролей (Keychain, диспетчер учётных данных Windows или
  связка ключей Linux), а не в файле. Без ключа приложение работает и пишет, что пропустило.

На экране **Состояние и ключи** видно, что уже настроено и что отключается без каждой недостающей части.
