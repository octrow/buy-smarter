# Security policy

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/octrow/buy-smarter/security/advisories/new),
not in public issues. Say what is affected (version or commit), how to reproduce it and what an attacker gains.

What happens next:

- a reply within 7 days, confirming the report or asking for details;
- a fix within 30 days of confirming it (sooner for anything that leaks keys or data), in a release whose notes name
  the issue;
- the advisory goes public once the fixed release is out, crediting you unless you ask not to be named. Please keep
  the details private until then.

Only the latest release and the latest commit on `main` get fixes.
